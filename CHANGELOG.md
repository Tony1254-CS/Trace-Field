# Changelog

## 1.0.0 - 2026-10-30

- Migrated TRACE to a Next.js App Router frontend, Express API, and Supabase Auth/Postgres/Storage architecture.
- Added owner-scoped missions and observations, private photo handling, RLS migration, API validation, and versioned backup restore.
- Preserved field observation responses, review-before-save, GPS accuracy, mission history, search, filters, and deletion confirmation.
- Added setup and architecture documentation. Live Supabase configuration and integration verification remain maintainer actions.
